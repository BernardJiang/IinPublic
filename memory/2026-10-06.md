# 2026-10-06

- Added an opt-in, default-off **Only exchange Talks with contacts** preference under Settings →
  Content Filters.
- Product decision: the preference gates Talk offers and Talk responses in both directions, but
  does not hide chatroom members or disable nearby/chatroom discovery.
- Enforcement covers outgoing room/direct/catch-up delivery, incoming Talk intake, outgoing
  answers and change-of-mind fanout, incoming answers, and cached actionable Talk rows. A missing
  contact list fails closed while the preference is enabled.
- Starter-practice contacts remain visible because their seed Talks are separate from actual
  network incoming clusters.
- Audited automatic location/micro-room behavior for a 10,000-person venue. Current code starts
  first-time users in `global` and only suggests a named location room; numbered `_part_N`
  overflow is reactive after publishing membership. It is not yet a safe automatic micro-room
  allocator at arena scale: all members are initially observed, an offline FIFO evictee leaves the
  room over capacity, eviction/frontier records are unauthenticated, split rooms never compact,
  and SPEC-5 has no behavioral scale test. A separate P0 privacy defect was found: public user and
  room paths can receive `trueLocation`/exact GPS even though comments and design say it stays
  local. Recommended direction is direct blurred-grid entry plus deterministic bounded lane
  assignment; exact global FIFO conflicts with coordinator-free pre-admission sharding and should
  apply only within a lane unless an admission authority/consensus mechanism is introduced.
