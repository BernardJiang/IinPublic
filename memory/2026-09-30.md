# 2026-09-30

- Product decision: ordinary chatbot behavior is deliberately simple. It first repeats a choice
  saved under the identical rolling context. A reusable answer taught at ROOT is an unconditional
  default for that exact question frame and follows it to any sequential position; a specific
  rolling-context answer overrides it. Every changed/missing frame is left to the user. There is
  no question-only, semantic, answer-presence, permanent, or suppressed fallback.
- Context memory v2 uses SHA-256 over the current normalized question and complete sorted choice
  set. Flow/route contexts roll forward from only the immediate parent context hash plus its
  selected answer; surveys start each question at root. Route siblings do not influence each
  other. User wording is “Same context” versus “Just once.”
- Legacy exact-question memory remains only for history/migration metadata and is excluded from
  normal resolution. Multi-select remains manual until the complete selected set can be stored
  atomically under one v2 context.
