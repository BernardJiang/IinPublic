# 2026-09-30

- Product decision: ordinary chatbot behavior is deliberately simple. It repeats only a choice
  the user saved under an identical known context; every changed or missing context is left to
  the user. No question-only, semantic, answer-presence, permanent, or suppressed fallback.
- Context memory v2 uses SHA-256 over the current normalized question and complete sorted choice
  set. Flow/route contexts roll forward from only the immediate parent context hash plus its
  selected answer; surveys start each question at root. Route siblings do not influence each
  other. User wording is “Same context” versus “Just once.”
- Legacy exact-question memory remains only for history/migration metadata and is excluded from
  normal resolution. Multi-select remains manual until the complete selected set can be stored
  atomically under one v2 context.
- Implementation and design are complete in the working tree, alongside earlier uncommitted Me/
  Talks fixes. Validation: typecheck, lint, complete unit command, integration, production web/
  server builds, and focused Chromium flow/context E2Es passed.
- A clean `build:server` previously omitted the Google hardware-attestation PEM and crashed E2E
  startup; the server build now copies this runtime asset into `dist/server`.
