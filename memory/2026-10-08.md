# 2026-10-08

- Product owner replaced the Global-first L1-L4/FIFO chatroom cascade with a simpler model:
  automatic small geographic Nearby rooms plus manually selected, content-addressed map Places.
- Nearby over-capacity handling subdivides geographically so closer people stay together; `C=498`
  and `K` remain global, versioned experimental values requiring simulation and three-phone tests.
- TechSupport is a pinned verified Contact only, never a room member, map pin, or headcount entry.
- Gun remains the database, with owner-private Talk/Me data SEA-encrypted and network-visible Gun
  limited to room/place control metadata. A local-only private Gun vs ciphertext replication remains
  an explicit implementation decision.
- Stranger Talk sessions are encrypted from first contact using signed identity and ephemeral keys;
  becoming a Contact pins durable identity/state rather than enabling encryption for the first time.
- Ordinary Talk delivery baseline is direct author-to-receiver with bounded concurrent links.
  Third-person phone forwarding is deferred/optional and disabled by default, not forbidden.
- Canonical design written in `docs/design/nearby-and-place-chatrooms.md`; technical spec updated to
  v4.9 and TODO OPEN-40 rewritten as the migration plan. Legacy room-tree/business design files are
  marked superseded.
