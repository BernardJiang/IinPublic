# 2026-10-23

- Chatrooms now preserve the v3 protocol roster order in both the compact root person list and
  the opened room member list: public distance, established identity, then the daily per-viewer
  hash. Relationship statistics remain visible but no longer reorder people.
- Removed the redundant visible `📍 Nearby` scope label from the AppBar. The selected folder or
  room-detail heading names the scope; the AppBar center now shows only changing user/match counts.
- Replaced Tag and Pair-tag checkboxes with compact one-tap `Pass` and `Like` controls. Left swipe
  passes and right swipe likes; incoming itself is the implicit not-yet-decided state. Passed tags
  can be liked directly, and liked/copied tags can be passed directly. Tags have no manual-response
  option. Flow, Survey, and Route keep their manual/automatic response paths, left-swipe Ignore,
  down-swipe Retain, and no right-swipe decision.
- Diagnosed the Android Settings delay reported on Honor Magic V3 1.0.187. The 1.0.187-only
  presence change did not directly touch Settings; the blocking path was older synchronous work:
  the full hidden Settings tree was built during startup and rebuilt on every Settings tap, which
  also started a synchronous localStorage size scan before its first await. Settings is now built
  only while visible, its tab chrome paints before the on-demand render, Storage and Download
  refresh only when opened, and Back hides the detail parent before resetting its children.
  A rebuilt C10 trace reduced the Settings click task from ~147 ms to 19.5 ms and showed the active
  tab immediately with the next frame at ~43 ms; Download and Back painted in ~40 ms and ~22 ms.
  Focused unit tests, typecheck, lint, integration tests, Android debug build, and all 9 Settings
  navigation E2E cases pass. The exact Magic V3 is not connected, so its original five-second trace
  remains unmeasured on-device.
- Follow-up: the Honor Magic V3 / FCP-AN10 connected later with 1.0.187 and was updated in place to
  1.0.189. A controlled pre-update trace measured a 64.5 ms Settings click task; the same trace on
  1.0.189 measured 4.0 ms with the next frame at 6.7 ms, while Download and Back were both under
  5 ms. The release AAB was rebuilt and signed by the pinned official certificate
  (`6B:35:AB:…:92:5A`); its SHA-256 is recorded with the build artifact.
- Removed the synthetic Nearby room from the Chatrooms browser. Nearby remains an internal Talk
  delivery scope, but its people, headcount, and group-switch controls now live directly on the
  root screen; when no custom Place exists, no rooms section is shown. People are listed first and
  custom Places appear below them. Custom Place rows are the only enterable rooms and use a door
  (`🚪`) instead of a folder icon. Focused unit tests,
  typecheck, lint, production web build, and the one-user/two-user browser regressions pass.
