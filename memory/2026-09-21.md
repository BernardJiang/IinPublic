# 2026-09-21

- Defined the balanced production security posture for TechSupport and ordinary users: keyless
  public relay, cold encrypted root, short-lived delegates for routine support, automatic browser
  v3/Android Keystore custody for normal users, and honest identity-loss behavior.
- Documented that the current TechSupport agent's root-key `localStorage` injection is an interim
  risk boundary. It must not run on the VPS or persist against remotely served code; a local
  signer/decrypter boundary is the next hardening step before TechSupport becomes high-trust.
- Enterprise controls such as HSMs, threshold approval, and formal audits are deferred until scale,
  regulation, staffing, or threat level justifies them.
- Added ordered TechSupport hardening work as OPEN-27 through OPEN-30. Began OPEN-27 by making a
  production relay reject configured TechSupport keys and adding a local encrypted-vault delegate
  issue/revoke CLI that publishes only verified signed grants. The HTTP route rejects invalid
  grants and signed pre-revocation replay.
- Continued OPEN-27 after commit `0b6d751e`: delegate state is now reconciled monotonically across
  HTTP, embedded-node relay, live Gun, and verified browser cache. Root-signed revocations are also
  written to a separate append-only discovery root so a stale mutable slot cannot resurrect a
  grant for a fresh client that can retrieve the tombstone.
- Production web builds reject and erase the legacy TechSupport root browser injection. The
  headless root agent now refuses non-loopback URLs and remains only as a temporary dev/E2E
  harness; production issue/revoke uses the encrypted-vault CLI and routine support uses delegates.
- Reworked the opt-in Android TechSupport delegate E2E so it no longer boots a root browser: the
  Node test process signs and posts a public grant, the Honor phone opts in and answers, and audit
  metadata is checked through the keyless relay. The spec compiles/lists without hardware; its
  next physical execution still requires the configured Android devices and real signing fixture.
