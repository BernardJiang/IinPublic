- Added P2P security requirements to the roadmap/TODO: users publish SEA public keys only, private keys must be encrypted at rest on user-controlled devices, relay paths should expose only routing/signaling metadata, and direct P2P messages require authenticated end-to-end encryption plus signed anti-replay envelopes.
- Added multi-device privacy requirements: each device should keep its own public SEA identity, trusted devices can be linked by QR/pairing code into a private encrypted sync group, selected data can sync across devices, and relays must not be able to infer that multiple public device identities belong to the same human.
