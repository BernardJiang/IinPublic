- Closed the S3 explicit-relay native direct-message TODO. Added a browser +
  Electron native-app E2E that creates the same canonical direct pair
  conversation on both peers, connects direct P2P through explicit HTTP
  signaling, sends a browser direct/manual conversation message, and verifies
  the native UI renders it.
- The E2E exposed two real bugs: native direct-P2P session setup could stall
  before session creation because it rediscovered the peer from local Gun
  instead of using the known conversation `otherUserId`; embedded
  `/api/users/:id` could return a local Gun metadata stub without `pub`/`epub`
  instead of falling through to the upstream hub public identity.
- Fixes: direct subscription/session warmup now passes the `otherUserId` hint;
  web public-user lookup prefers the HTTP relay fast path; embedded user routes
  fall back to the hub when local user data lacks `id`, `pub`, or `epub`.
- Verification: `npm run test:type`; focused Jest set
