# 98-match-collection-controls

covers: SPEC-3.7, SPEC-6.1

Match collection (outing) on a phone-width screen, after the owner's rule of 2026-11-09 (no buttons
inside views): the Nearby list has no outing card and no buttons. Tapping the Nearby status line in
the AppBar switches to Contacts narrowed to the people the current collection reached (a "📣 …"
chip); the chip's ✕ shows everyone again. Broadcast stays the toolbar's button and fills the
current collection; collection on/off stays in Settings.
