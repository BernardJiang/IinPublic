# 89-talk-editor-mobile-layout

covers: SPEC-13.2, SPEC-26.2

Talk editor compact phone layout at 390px: the editor shell fills the viewport exactly with no
horizontal overflow, the four talk-type cards tile two-per-row within the width, and Create stays
visible and in the viewport while advanced controls (adult flag) sit behind a collapsed "More"
disclosure. Opening More keeps Create reachable, switching type keeps the disclosure state, and a
simple tag talk can be titled and created from the compact layout.
