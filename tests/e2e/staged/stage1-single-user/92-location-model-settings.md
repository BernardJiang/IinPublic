# 92-location-model-settings

covers: SPEC-6.3, SPEC-6.1

The simplified location model in Settings: Resident (blurred GPS) or Traveler ✈ (chosen point),
one area size, quiet places with Blur me more / Hide me, the Talk audience in Talk Behavior, and
one distance unit. Resident is the default with area-size options and no distance filter; Quiet
blurs to Regional, Hide me leaves Nearby for the contacts-only scope, and turning it off returns;
Traveler gets no GPS — a random on-map point until one is chosen, then Nearby resolves from it;
the distance-unit choice is reflected in the location section's options.
