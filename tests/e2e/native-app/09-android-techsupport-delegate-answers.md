# 09 — Android TechSupport delegate answers
covers: SPEC-5.3, SPEC-19.7

A physical Android phone receives a signed TechSupport delegation grant and answers independent
questions from another Android phone and the packaged macOS app using the delegate's own key.
The root signing pair remains outside every remotely served page and client device.

Run with `E2E_REAL_ANDROID_TECHSUPPORT_DELEGATE=1` and two configured Android devices.
