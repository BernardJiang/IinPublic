# 16 — Five-way cross-host live peer matrix
covers: SPEC-3.4, SPEC-5.5, SPEC-19.4

The packaged macOS app, a physical Android phone, local Chromium, Ubuntu Chromium, and Windows
Chromium share one live hub and exchange matching Talks. The run explicitly proves the Ubuntu ↔
Windows edge in both directions in addition to the Mac and Android edges.

Run with `E2E_REAL_FIVE_WAY_LIVE_PEER=1` and all configured remote/device hosts.
