# 14 — Ubuntu cross-host live peer
covers: SPEC-3.4, SPEC-5.5, SPEC-19.4

Real Ubuntu Chromium joins a live hub with a macOS browser, the packaged macOS app, and a physical
Android phone. Explicit matching-Talk exchanges prove both directions of the Ubuntu ↔ Mac browser
and Ubuntu ↔ Android boundaries.

Run with `E2E_REAL_UBUNTU_LIVE_PEER=1` and the configured Ubuntu and Android hosts.
