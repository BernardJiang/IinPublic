# 15 — Windows cross-host live peer
covers: SPEC-3.4, SPEC-5.5, SPEC-19.4

Real Windows Chromium joins a live hub with a macOS browser, the packaged macOS app, and a physical
Android phone. Explicit matching-Talk exchanges prove both directions of the Windows ↔ Mac browser
and Windows ↔ Android boundaries.

Run with `E2E_REAL_WINDOWS_LIVE_PEER=1` and the configured Windows and Android hosts.
