# 08 — Android TechSupport conversation answer flow
covers: SPEC-7.6, SPEC-19.7

An ordinary user on a physical Android phone asks several questions through the built-in
TechSupport conversation. A desktop TechSupport operator answers through the ordinary
conversation UI, exercising the server-backed support exception across a real mobile boundary.

Run with `E2E_REAL_ANDROID_TECHSUPPORT_ANSWER=1` and a configured Android device.
