# 20 — macOS and Windows packaged desktop peers
covers: SPEC-3.4, SPEC-5.5, SPEC-19.4

The packaged macOS and Windows desktop applications share one live hub. Each authors and
broadcasts a matching Talk that the other completes, covering the packaged cross-host desktop
boundary rather than browser stand-ins.

Run with `E2E_REAL_MACOS_WINDOWS_DESKTOP_LIVE_PEER=1` and the configured Windows host.
