# Archive Docs

This directory category is for historical or reference material that should not be treated as
the primary source of truth for the current repo.

Archived material includes:

- `reports/` — merged-project summaries and phase completion reports from earlier iterations
- `testing/` — stale coverage snapshots and old test-status guides
- `guides/` — phase-era quick-start/result guides that reference retired example paths
- `dev/` — historical migration notes that reference retired source/test layouts
- `merged-source/` — source notes that have already been merged into the technical specification
- `reference/` — legacy README files from merged source projects
- `imported/` — imported `.docx` files
