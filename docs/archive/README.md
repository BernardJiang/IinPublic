# Archive Docs

This directory category is for historical or reference material that should not be treated as
the primary source of truth for the current repo.

Archive candidates already present elsewhere in `docs/` include:

- merged-project summaries
- phase completion reports from earlier iterations
- imported `.docx` files
- legacy reference READMEs from merged sources
- older plans that describe a different file layout or delivery phase

Current source-of-truth docs are listed in [Current Docs](../current/README.md).
