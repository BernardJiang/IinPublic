# Reproducible build verification

Verified on 2026-08-12 from one checkout with Node 26.4.0, Xcode 26.6, Gradle 8.4 and the repository lockfiles. Reproducibility covers independently generated application payloads. Developer/distribution signatures are environment-owned outputs and are not claimed reproducible.

## Deterministic build stamp

`scripts/stamp-build-id.js` uses `SOURCE_DATE_EPOCH` when supplied, otherwise the current Git commit time. Source archives without either value retain an explicit wall-clock fallback. The build ID remains the Git short SHA when available.

## Results

| Platform | Repeated build boundary | Result | Manifest SHA-256 |
|---|---|---|---|
| Web + server | Two `npm run build:embedded` runs; every file in `dist/web` and `dist/server` | Identical | `ee9baa75514a1a7ba064d103a716d5929597ebf2f15bc48131eeff8cf6c56f44` |
| Desktop macOS | Two `electron-builder --dir` runs after dependency staging; unsigned/ad-hoc `.app` file manifest | Identical | `8f81ffd551a18b073908b50a0557560a49bd5b8607e58978fe0fde00753a68bb` |
| Android | Two forced `:app:assembleDebug` runs; all extracted APK ZIP entries | Identical | `8b9f2564cbd8ea93cbfcd4ce43e3b43e931f11e595c35210fd5311c002a77c83` |
| iOS | Two clean unsigned Release simulator builds at fixed `-derivedDataPath /tmp/iinpublic-ios-repro`; `.app` file manifest | Identical | `9f59c1ad09526eb153e0475d4421ea1269a4c6b9b0debecdab1554784d98e0c9` |

The complete Android debug APK byte hash is not stable because APK signing-block bytes are outside ZIP entries and are regenerated by the debug signer. The extracted payload and every signed ZIP entry were identical. Release verification must compare the payload before applying the release keystore signature, then separately verify that signature and certificate.

iOS builds made under different absolute derived-data paths embed those paths in Swift debug/link metadata and are not byte-identical. The supported reproducible command therefore uses a fixed documented derived-data path. Distribution signing/notarization is a separate provenance step.

## Commands

```bash
npm run build:embedded

cd android
./gradlew :app:assembleDebug --rerun-tasks

cd ..
bash scripts/stage-desktop-prod-deps.sh
npm --prefix platforms/desktop run dist -- --dir

xcodebuild -quiet \
  -project platforms/ios/IinPublic.xcodeproj \
  -scheme IinPublic -sdk iphonesimulator -configuration Release \
  -derivedDataPath /tmp/iinpublic-ios-repro \
  CODE_SIGNING_ALLOWED=NO clean build
```

For independent verification, run each command twice from identical source and lockfiles, generate a sorted `shasum -a 256` manifest of the stated boundary, and compare the manifests. For Android, unzip both APKs before generating the manifest.
